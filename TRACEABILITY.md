# Directive traceability

Maps each design directive to the code that implements it and the tests that verify it.
Engine = `skillpath/engine.py`, config = `skillpath/config.py`, API = `api/main.py`.
Test files: `tests/test_engine.py` (E), `tests/test_progress_nudge.py` (P), `tests/test_api.py` (A),
`tests/test_adapter_and_harness.py` (H).
