# Design decision log

Each entry records the decision, the directive it serves (DD1–DD10, see TRACEABILITY.md), the alternatives
considered, and the reason. Entries dated 2026-10-05 were made while building the first version of the prototype.

| # | Date | Decision | Directive | Alternatives considered | Reason |
|---|---|---|---|---|---|
| 1 | 2026-10-05 | Engine is a pure, deterministic rule set: no randomness, clock or network; all ties broken alphabetically. | DD2, DD10 | ML ranking; random tie-breaks | Every rule is measured by an evaluation metric (Q2 needs identical repeat output); deterministic rules are testable and auditable. |
| 2 | 2026-10-05 | Similarity is Jaccard J(S,O)=\|S∩O\|/\|S∪O\| between recognised skills and each occupation's essential skills. | DD2 | Cosine on embeddings; raw overlap count | Specified; transparent and explainable ("you have 2 of 5 skills"); no external model. |
| 3 | 2026-10-05 | Nearest occupations = top K=3 by J, ties by occupation name A→Z (case-insensitive, then exact). | DD2 | K=1; K=5; tie by row order | Specified K; name order is stable regardless of CSV row order. |
| 4 | 2026-10-05 | Candidate score = mean J over the K nearest after adding the skill minus mean J before (adjacency gain); sort by gain desc, then skill A→Z. Primary = first; alternatives = next 3. | DD1, DD2, DD6 | Most frequent missing skill; target-occupation gap | Specified; picks the smallest step towards several nearby occupations at once. |
| 5 | 2026-10-05 | All similarity arithmetic uses exact fractions (`fractions.Fraction`). | DD2 | Floating point | Mathematically equal gains can differ in floating point, which would bypass the alphabetical tie-break. |
| 6 | 2026-10-05 | (Superseded by #34.) When fewer than K occupations overlap with the profile, zero-similarity occupations still fill the K slots (spec applied literally). **Correction (2026-10-05, real skill map):** an earlier note said such skills never rank first; that held only for the test fixture. With small profiles a skill from a zero-similarity occupation CAN rank first (e.g. 'statistics' alone gets an agricultural-science skill). | DD2 | Exclude J=0 occupations | Follows the specification exactly; raised with the researcher for a decision (see #34). |
